# AI Recommendation System - Project 3

## Description
This is a simple console-based AI recommendation system that suggests items based on user-selected categories.

## Features
- Movie recommendations
- Book recommendations
- Sports suggestions
- Music recommendations
- Technology topics
- Loop-based interaction (user can try multiple times)

## How it works
User selects a category → system displays relevant recommendations.

## Example Categories
Movies, Books, Sports, Music, Technology

## Output
Shows list of recommended items and total count.
